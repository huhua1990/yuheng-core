# 故障日志优先

接口失败、页面异常、构建/测试报错时先保存复现输入、发生时间、当前版本、错误堆栈、请求与响应、相关日志位置，再限定代码搜索范围。

- 从实际启动配置和进程确认日志位置，不凭空指定目录；优先使用已有本地日志与只读诊断。
- 日志遮蔽口令、令牌、个人敏感数据；不通过关闭认证、租户过滤或吞异常来“修好”。
- 分开识别环境、依赖、测试装配与业务行为失败；只有目标行为断言失败可作为 TDD 红灯。
- 根因明确后编写最小复现测试，修复并重跑原复现与受影响回归；证据归同一 `workId`。
- 环境暂不可用时先完成独立单元测试和静态检查，记录未验证范围，不能将未联调标记为已完成。
