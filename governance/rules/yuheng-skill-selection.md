# Yuheng 技能选择

| 当前产物 | 入口 |
|---|---|
| 原始需求、口头想法 | `yuheng-requirement-to-spec` |
| 已确认规格 | `yuheng-spec-to-plan` |
| 已确认计划，或实现已存在但要求验收 | `yuheng-delivery-execution`，按可核实授权范围验证 |
| 阶段不清楚 | `yuheng-workflow-router` |
| 明确要求完整实施 | `yuheng-full-workflow` |

专项技能由入口按需加载：需求探索、任务拆解、知识路由、后端/页面交付、菜单权限、TDD、API/UI 验证、自检和完成前验证。读标准目录 `<skill-name>/SKILL.md`；旧平铺 `.md` 仅作兼容指引。

不要把全部专项技能同时加载，也不要让用户自己从全部技能中挑选。技能缺失或引用失效时先修复本地安装/快照，不假装调用成功。
