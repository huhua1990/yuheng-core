# Yuheng 交付检查规则

适用范围：所有由 AI 声称"已完成"的 Yuheng 开发任务。

---

## 交付前最小检查

### 后端任务

1. 至少说明已执行的验证：编译、测试、脚本检查或接口烟测中的一种或多种。
2. 明确说明是否按 TDD 执行，并给出本次"先写测试 → 红灯 → 实现 → 绿灯"的证据。
3. 明确说明是否已检查现有 API / service 家族，避免新增重复能力。
4. 确认返回结构遵守统一 `CommonResult` 契约。
5. 涉及当前用户时，确认使用 `SecurityFrameworkUtils` 或框架既有上下文能力。

### 前端任务

1. 说明页面是否复用框架共享 Store、预热数据和权限模型。
2. 确认没有重复拉取框架已预热的数据。
3. 说明最小页面自测或脚本验证结果。

---

## 输出要求

- 没有验证证据时，不能说"已完成"或"已通过"。
- 如果因环境限制无法验证，必须说明未验证项、阻塞原因和风险边界。

---

## 检查清单

### 后端
- [ ] 代码已编译通过
- [ ] 单元测试已通过
- [ ] TDD 证据完整（红灯 → 实现 → 绿灯）
- [ ] 已检查现有能力，无重复实现
- [ ] 返回值使用 `CommonResult`
- [ ] 用户上下文使用框架 API

### 前端
- [ ] 页面可正常访问
- [ ] 复用框架 Store
- [ ] 无重复数据请求
- [ ] 权限模型正确使用
- [ ] Console 无错误
