# 复用优先原则

适用范围：Yuheng 产品线所有功能增量开发。

---

## 复用优先原则

1. 新增 controller 前，先检查现有 API 家族是否已经覆盖或接近覆盖目标能力。

2. 新增 service 前，先检查现有 domain/service 是否可扩展。

3. 新增页面上下文或共享状态前，先检查 `yuheng-ui` 是否已有共享 Store 或框架预热数据。

4. 新增权限逻辑前，先检查页面是否已可复用权限模型或既有角色模型。

---

## 默认决策

- 能扩展现有能力时，不新建平行实现。
- 不能复用时，要明确说明"为什么现有能力不适合"，再新增。
- 页面内禁止维护第二套用户、菜单、组织、角色、字典、参数缓存。

---

## 风险提醒

如果跳过复用检查，产品线会在 AI 驱动下长出多套相近实现，后续维护成本会快速上升。
