- 后续已将前端安装、类型检查和构建接入 Demo Maven `generate-resources`，失败将中断打包，并在复制新资源前清理生成目录中的旧静态文件。隔离构建使用本地 core UI 包及公共 npm registry，成功生成包含 323 项前端资源的 JAR；Maven 离线并不代表 npm 离线，本地配置的内网 npm 仓库超时及缓存缺失时构建如预期失败。消费端独立锁文件尚缺，依赖解析可复现性仍待完善；npm 本次报告 22 项依赖漏洞，尚未逐项评估。此构建尚未部署到现有服务。
